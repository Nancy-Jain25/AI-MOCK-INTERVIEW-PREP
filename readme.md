# AI Mock Interview Platform

A full-stack mock interview platform for SWE internship candidates.
Built progressively from HTML/CSS/JS → React → Node.js → MongoDB → AI integration.

## Tech Stack
- **Phase 1:** HTML, CSS, JavaScript
- **Phase 2:** React
- **Phase 3:** Node.js + Express
- **Phase 4:** MongoDB
- **Phase 5:** Gemini/OpenAI API

## Features
- Create a profile and select your target role
- Take timed mock interviews
- Receive AI-generated feedback on your answers
- Track performance over time

## Getting Started
Open `prototype/index.html` in your browser to run Phase 1.
